⚙ One-time setup required

  1. Go to console.firebase.google.com → Create a new project (free Spark plan).
  2. In the project: Build → Realtime Database → Create database → choose "Start in test mode".
  3. Go to Project Settings → Your apps → Web app → register an app → copy the firebaseConfig object.
  4. Open both receiver.html and controller.html in a text editor and paste your config into the firebaseConfig block near the top of each file.
  5. Host both files on GitHub Pages (free): create a repo, push the files, enable Pages under repo Settings → Pages.
  6. Open receiver.html on each TV screen (use kiosk mode: chrome --kiosk https://yourname.github.io/signage/receiver.html).

Local files (images, videos, HTML slides)

Run serve-local.py on this laptop to serve files over the venue WiFi.
Step 1: Open a terminal and run: python3 serve-local.py
Step 2: The script prints your local IP, e.g. http://192.168.1.42:8765/
Step 3: Put your files (PNG, MP4, HTML, …) in the same folder as the script.
Step 4: Paste the URL into the field above, e.g. http://192.168.1.42:8765/opening-slide.html

The TV screens and this laptop must be on the same venue WiFi for local URLs to work.
